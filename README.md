# Resume Category Classification

## Project Description
Resume Category Classification is a machine learning project that classifies resumes into different job categories based on their content. It uses a Flask web application to make predictions.

## Technologies and Tools Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML and CSS
- Docker
- Git and GitHub
- AWS EC2

## How to Run the Project Locally

### 1. Clone the Repository
```bash
git clone https://github.com/YUKTI0807/resume-classifier.git
cd resume-classifier
```

### 2. Create a Virtual Environment
```bash
python -m venv venv
```

### 3. Activate the Virtual Environment

**Windows:**
```powershell
venv\Scripts\activate
```

### 4. Install Dependencies
```bash
pip install -r requirements.txt
```

### 5. Run the Application
```bash
python app.py
```

### 6. Open in Browser
Visit http://127.0.0.1:5000/ in your browser.

## Project Features
- Resume text processing
- Automatic resume category prediction
